Every mainstream LLM writes the same way: predict one more token, append it, repeat. That bakes in two assumptions: text is produced **in order**, and **one token per forward pass**. Diffusion language models (dLLMs) drop both.

## Two ways to write a sentence

An autoregressive (AR) model factorizes a sequence $x = (x^1, \dots, x^L)$ left to right:

$$
p_\theta(x) = \prod_{i=1}^{L} p_\theta\!\left(x^i \mid x^{<i}\right)
$$

So $L$ tokens take $L$ forward passes, and an emitted token is never revisited.

A masked diffusion model starts from $L$ positions that are all `[MASK]`. Each step, the network reads the **whole** sequence (attention is bidirectional), predicts every masked position, and keeps the predictions it is most confident about. A few steps later nothing is masked.

<DecodeDemo caption="Both rows generate the same 18 tokens. The AR model needs 18 forward passes; the diffusion model needs ⌈18 / k⌉. Drag the slider to change k, the number of tokens committed per step." />

Two things change: **order becomes a choice** (the end of a sentence can be fixed before the middle), and **the number of steps is a knob**, not $L$.

<Note>
	Training is a generalized BERT: hide a random fraction of the tokens, anywhere from 0% to 100%, and learn to fill them back in. Covering every fraction is what lets sampling start from a fully masked sequence. M02 and M03 make this precise.
</Note>

## What it costs

- **Parallel tokens are guessed independently.** If the model is split between "New York" and "San Francisco", committing both words in one step can give "New Francisco". Fewer tokens per step avoids this, at the price of more steps (M05).
- **No free KV cache.** With **bidirectional attention** every position can change every other position's representation, so the AR cache does not apply directly (M04, P01).
- **Fixed canvas.** Sampling starts from a fixed number of masked positions, so the **length** has to be chosen up front (M04).

<Note kind="question">
	How many tokens can we safely commit per step, and can the model tell us when it is safe? This comes back in M05 (sampling) and P02 (parallel decoding).
</Note>
