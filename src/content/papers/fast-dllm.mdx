Two tricks that make LLaDA and Dream an order of magnitude faster without touching the weights. Diffusion LLMs
cannot use a standard KV cache because attention is bidirectional, so the paper decodes block by block and reuses
keys and values that barely change between steps. And instead of unmasking a fixed number of tokens per step, it
unmasks every token whose confidence clears a threshold.

<Highlight page={5} line={36} text="Key-Value activations at adjacent inference steps within a block are highly similar." color="green" />

<Annotation page={4} line={25} text="Masked Diffusion Model (MDM)" color="green">
Builds on the masked diffusion setup; nothing here is specific to one model, which is why it works on both LLaDA and Dream.
</Annotation>

<Annotation page={5} line={41} text="Confidence-Aware Parallel Decoding">
The second half of the paper. Compare with fixed top-$k$ unmasking per step: a threshold adapts the number of tokens committed to how sure the model is.
</Annotation>

<Annotation page={5} line={47} text="exceeding a threshold" color="pink">
The rule: unmask token $i$ when its confidence $c_i = \max_v p_\theta(v)$ exceeds $\tau$. If none qualifies, unmask the single most confident one so decoding always makes progress.
</Annotation>
